# Experimental Methods Overview

## Study System
- Species: Daphnia lumholtzi
- Clone source: Saguaro Lake, AZ
- Generations tracked: F0 through F5

## Experimental Design
- Treatment: Fish-conditioned medium vs control
- Measurements: Every 2 days
- Traits: Headspine, tailspine, body length

## Statistical Approach
- Mixed-effects models
- Bayesian and frequentist analyses
- Morphometric corrections for body size
